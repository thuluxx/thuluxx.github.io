In progress

VoltSight — Smart Motor Health Monitoring System

An IoT-based system that continuously monitors the health of an electric motor and flags problems early, instead of relying on fixed maintenance schedules or waiting for someone to notice a failure. Built for factory operators and maintenance engineers who need real-time visibility into motor condition, not just a post-mortem after downtime.

Type · Team project, hardware + full-stack Stack · ESP32, FastAPI, PostgreSQL, React

Hardware

  • ESP32 — reads sensors, sends readings over WiFi
  • Temperature sensor — flags overheating
  • Current sensor — flags overload / abnormal draw
  • Vibration sensor — flags bearing wear or imbalance
  • RPM sensor — tracks motor performance

Software

  • FastAPI backend receiving and processing sensor data
  • PostgreSQL storing historical readings
  • React dashboard for live data, history, and alerts
  • V1 goal: prove the full pipeline works end-to-end; ML-based anomaly detection planned for a future version
