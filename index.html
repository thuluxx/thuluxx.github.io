VoltSight — Predictive Maintenance Platform for Electric Motors

VoltSight is a collaborative IoT platform being built to detect early signs of electric motor failure before breakdowns occur. Using an ESP32, industrial sensors, a FastAPI backend, PostgreSQL, and a React dashboard, the system continuously monitors motor health and provides real-time analytics and maintenance alerts.

Type · IoT + Cloud + Full Stack Status · Architecture & Development Team · 2 Developers (CSE + EEE)

Hardware (EEE)

  • ESP32 Microcontroller
  • Temperature Sensor (DS18B20)
  • Current Sensor (ACS712)
  • Vibration Sensor
  • Breadboard & Wiring
  • Wi-Fi data transmission

Software (CSE)

  • FastAPI REST Backend
  • React Dashboard
  • PostgreSQL Database
  • Docker Development Environment
  • Real-time Motor Monitoring
  • Cloud Deployment (planned)
Predictive maintenance prototype focused on monitoring motor health, preventing unexpected failures, and building an end-to-end IoT cloud platform while learning modern backend and DevOps practices.
